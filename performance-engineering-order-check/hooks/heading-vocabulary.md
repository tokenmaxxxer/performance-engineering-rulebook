# Canonical heading vocabulary — order-check.sh

Case-insensitive phrase groups this gate recognizes as referring to the
same section, for the purpose of position-in-text order checking. A
proposal/record may use any phrase within a group; the gate matches on
first occurrence of any phrase in the group.

## "workload" group (must precede "evidence" group)
- workload characterization
- workload-actual
- workload profile

## "evidence" group (must follow "workload" group)
- percentile evidence
- percentile-evidence
- profiling evidence
